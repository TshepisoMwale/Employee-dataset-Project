# Employee-dataset-Project
Characteristics of Top-Performing Employees

This data analysis project focuses on identifying the characteristics and patterns associated with top-performing employees. For the purpose of this analysis, employees with an "Excellent" performance score are classified as top-performing employees.

1. Business Problem

The dataset contained several data-quality issues, including missing values, inconsistent date formats, and ambiguous or incorrectly defined column data. These issues were addressed through a combination of Excel and SQL data-cleaning techniques to prepare the dataset for analysis.

The objective of this project is to analyse employee data and identify patterns and characteristics associated with excellent performance. The insights generated can help a business better understand its high-performing employees and support workforce planning, performance management, and employee development.

2. Dataset Description And Data cleaning
   
The dataset contained several data quality issues that required cleaning and transformation before analysis. These included missing values in the Salary and Age columns, inconsistent date formatting, and employee Department and Region information combined within a single column.
The data cleaning process involved using Excel and SQL to improve the dataset's consistency and usability. Missing values were identified and addressed using Excel's Find and Replace functionality. The inconsistent date values were corrected using SQL queries, including ALTER TABLE and UPDATE, to ensure the date column followed a consistent format. The Text to Columns function in Excel was used to separate the combined Department and Region data into individual columns.
These cleaning and transformation steps produced a more structured and consistent dataset suitable for further analysis using SQL and Tableau.

3) Key Findings
   
The analysis identified the following characteristics among employees with an “Excellent” performance score:
•	Average age: The average age of excellent-performing employees is 32 years and 2 months.
•	Average salary: The average salary among excellent-performing employees is $85,491.61.
•	Department: Human Resources (HR) has the highest number of excellent-performing employees, with 36 employees.
•	Region: New York has the highest number of excellent-performing employees, with 38 employees.
•	Work arrangement: 89 excellent-performing employees work remotely, while 94 work from the office.
These findings provide a descriptive view of the characteristics and distribution of employees who achieved an “Excellent” performance score. They can help the business identify patterns that may be useful for workforce planning, performance management, and employee development.
